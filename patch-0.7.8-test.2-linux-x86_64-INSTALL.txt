Patch 0.7.8 (test.2): test build
=============================

Patch replaces Omarchy's audio with a pro mixer, router, meters and EQ,
plus optional DJ decks, an AI DJ, a visualiser, podcast tools and more.

You need
  - Omarchy (Arch Linux with Hyprland 0.56 or newer; check: hyprctl version),
    on an x86_64 computer
  - sudo rights (the installer adds a few Arch packages)

Updating from an earlier test build
  Run ./install.sh from this kit over the old one; no need to uninstall.
  The running Patch hands over to the new version at once, without a gap,
  and your library, settings and layouts stay.

Install
  1. Download patch-0.7.8-test.2-linux-x86_64.tar.gz (and the .sha256 next to it)
  2. Open a terminal in the folder you downloaded it to, and run:

       sha256sum -c patch-0.7.8-test.2-linux-x86_64.tar.gz.sha256
       tar xzf patch-0.7.8-test.2-linux-x86_64.tar.gz
       cd patch-0.7.8
       ./install.sh

  3. Choose Minimal (Patch replaces Omarchy's audio), Full (everything)
     or Custom (pick modules), then your default layout.
  4. Read the short guide the installer shows at the end, then log out
     and back in once (real-time audio starts with the next session).

First steps
  - Open "Patch" or one of the "Patch …" apps from the launcher (Super+Space).
  - In any Patch window, Ctrl+K opens the controller: every Unit, the
    layouts and Setup.
  - The bar's volume menu has a Patch section: Patch itself is selected,
    which gives the full Mixer console.
  - omarchy-patch welcome shows the guide again.
  - Phone remote (Full, or Custom with DJ): sign this machine in to
    Tailscale first, then open https://<this machine>.ts.net:8124 on a
    phone signed in to the same Tailscale account. Without Tailscale the
    remote is installed but stays off; run ./install.sh again after
    tailscale up.

Uninstall
  In the same folder: ./uninstall.sh   (Omarchy's own audio comes back;
  ./uninstall.sh --purge also removes your library and settings)
